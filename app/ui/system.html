How this page works

The server checks the sync every 5 minutes in the background. The page shows the last result and never waits on the network. Check now runs a check at once.

A file loads when you open it. Edit opens the text in a box. Save writes the file, commits it alone, and pushes to GitHub. If an agent changed the file first, the save stops, your text stays in the box, and you can load the new version.

After a change to a charter, the lessons or a skill, from you or from an agent, the server rebuilds the map within about 10 seconds. This page loads new data every 30 seconds.
