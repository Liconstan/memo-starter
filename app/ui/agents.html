Set up phone

The Inbox also runs from GitHub, so you can read and answer memos when this computer is off. Each phone or computer needs one setup link, once.

  1. On github.com, make a GitHub key: Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Choose only the private Inbox repository, and under Repository permissions give Contents: Read and write. Copy the key. It starts with github_pat_.
  2. Paste the key below and press Make setup link.
  3. Copy the link and send it to your iPhone. Open it in Safari once. Then tap Share and Add to Home Screen.
  4. Open the Memo app from the Home Screen. It has its own storage, so paste the same link into its form once more. Then delete the link from wherever you sent it.

A look inside

To look at a session, run this in a terminal:

tmux attach -t memo-main

To leave it, press ⌃b, then d.

"Stop" asks the agent for a recap, then ends the session. The next session gets the recap after its charter.
